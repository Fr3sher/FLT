# SeedVR2

SeedVR2 1.0.5 supplies faithful restoration, high-resolution tiling, explicit model preparation, settings, finishing, image actions and help. It requires LDS plug-in API 1.20 and a configured ComfyUI, but no other LDS plug-in. This core includes NumPy for the shared CPU photo-finishing helper; no ML environment is required for sharpening or grain. Use Prepare SeedVR2 to prepare its node pack, qualified dependencies and two model files together; then restart ComfyUI yourself and re-check its live readiness. Tiling uses the optional TTP node pack. No GPU or model download runs merely by installing the LDS package.

Managed node preparation currently supports a recognized local ComfyUI Windows portable with Python 3.12 or later. The manifest pins the dependency profile; an incompatible existing environment is refused before the group's model downloads, without replacing its packages. For other ComfyUI installations, prepare the upstream node pack in ComfyUI first; LDS can then prepare missing model files and check the loaded classes. Node preparation and CPU import tests do not qualify GPU rendering. The author wheel and its reproducible build instructions are in `resources/wheels/`.

The engine ID `seedvr2`, `/api/seedvr2/models`, model folders, setup action IDs, historical result metadata, help anchors and news IDs are preserved. Disabled or absent SeedVR2 cannot submit work or offer its installers.

Finishing is independent: `seedvr2.finish_sharpen`, `seedvr2.finish_grain` and `seedvr2.finish_grain_saturation`. LDS copies missing values from the historical shared `improve.*` recipe before applying defaults or accepting a new settings edit. Loading is read-only; the next normal save persists the migration. Existing Seed values, including zero, win. Later Klein changes never alter Seed's persisted recipe. Colour correction remains inside the SeedVR2 node and is not applied twice.

For installations with the old combined image_upscale 1.0.0 archive, the Store upgrades Klein Improve to 1.1.0 in the same installation plan before loading SeedVR2. It does not rewrite the old archive or add a dependency between the new products.

TTP compatibility is tested against `Comfyui_TTP_Toolset` commit `12d5279438bfefc058a269eae805ceab6047777f`. It derives overlap from the minimum covering grid, with no overlap-rate input. Exact multiples have no overlap; its assembler also fails on certain odd overlaps. Safe positive geometries retain that workflow. Otherwise LDS builds explicit overlapping crops with standard ComfyUI nodes and blends each row before blending rows, preserving the full target and its intersections. A new 2048×2048 result at tile size1024 uses nine actual tiles; previous four-tile results and metadata are unchanged.

The fallback requires ComfyUI's standard `ImageCrop`, `ImageBatch`, `EmptyImage`, `ImageFromBatch`, `ImageCompositeMasked`, `SolidMask`, `FeatherMask` and `MaskComposite`, checked alongside TTP. Missing standard nodes require updating ComfyUI, not installing another node pack. The saved job metadata and graph describe the actual grid. Bank and Dataset use the same enqueue path; their confirmation dialogs do not currently preview an exact tile count.

The tile and VAE size remain bounded by `seedvr2.tile_px`, with inference batch size one. More overlap can mean more inference passes and larger image buffers. A balanced batch tree avoids a quadratic concatenation chain, and row-first assembly limits full-height canvases to the number of rows. Assembly still holds image/mask buffers and full-frame outputs: this does not promise constant total RAM or VRAM. CPU tests cover complete pixels, edge artifacts and intersections, odd/asymmetric sizes, the512 setting, safe TTP preservation and dependency diagnostics. A model can still introduce differences between tiles; GPU image quality needs its own qualification.

A reachable ComfyUI with an unreadable node catalogue is reported as an unknown tiling state. Re-check before changing the installation: no missing nodes have been confirmed, and tiled work is not admitted until discovery succeeds.
